# my-first-repo

Практическая работа №16 — Основы Git и GitHub.

## Файлы проекта

- `index.html` — главная страница
- `style.css` — стили оформления
- `README.md` — описание проекта

## Команды Git

```bash
git init
git add index.html
git commit -m "Initial commit: add index.html"
git add style.css
git commit -m "Add style.css: basic styling"
git remote add origin https://github.com/strawberrybwin-art/my-first-repo.git
git branch -M main
git push -u origin main
git pull origin main
```
